✅
Texte sur aqua = navy. Toujours color: var(--navy) sur fond aqua. Jamais blanc — le contraste WCAG AA n'est pas atteint.

13 — Règles

Règles de conception

Principes non négociables pour maintenir la cohérence du site.

Accessibilité (WCAG)

✅
Texte sur fond aqua (#22D3EE) = couleur navy (#0D1025). Jamais blanc — ratio de contraste insuffisant (2.8:1 vs 4.5:1 requis AA).
✅
Focus visible sur tous les éléments interactifs. Border accent + box-shadow 3px aqua translucide.
✅
Labels explicites sur tous les champs de formulaire. Pas de placeholder seul.

Architecture fichiers

✅
Single-file par page. HTML + CSS + JS dans un seul fichier .html. Pas de fichiers CSS ou JS séparés. Permet le déploiement par copier-coller sur GitHub.
✅
Google Fonts uniquement. Pas de polices auto-hébergées. Chargement via <link> dans le <head>.
✅
Images en base64. Le portrait et le logo SVG sont embarqués en base64 dans le HTML. Zéro dépendance externe pour les assets.
✅
Base href. Toutes les pages incluent <base href="..."> pour gérer staging vs production. Liens relatifs partout.

Cohérence inter-pages

✅
Nav identique partout. 4 liens + 1 CTA. Seule la classe .active change selon la page.
✅
Footer identique partout. 4 colonnes + ligne légale. Aucune variation.
❌
Pas de page sans GA4. Chaque fichier HTML doit inclure le tag G-M0LENY960B.
❌
Pas de CSS framework. Pas de Tailwind, Bootstrap, ou autre. Tout est vanilla CSS avec variables.

Wording & ton

✅
Vouvoiement partout sur le site. Tutoiement uniquement dans les échanges email clients.
✅
"Télécharger" pour le PDF simulateur (pas "Recevoir", pas "Débloquer").
✅
Prix TTC pour particuliers. Prix HT (TJM) pour professionnels. Toujours mentionner TVA art. 293B.
✅
Micro-copy rassurante. "Sans engagement", "Gratuit", "Aucun spam", "Vos données ne sont jamais revendues".
❌
Pas de jargon BTP non expliqué. "DPE" doit être accompagné de "Diagnostic de Performance Énergétique" au moins une fois. "RFR" → "Revenu Fiscal de Référence".

Nommage fichiers & documents

✅
Format ADORA : ADORA_NomsClient_Sujet_Dateaaaammjj
Exemple : ADORA_NAWAWI_Note_Synthese_20260330.docx
✅
Pages web : kebab-case français — a-propos.html, sur-mesure.html, audit-avant-achat.html
